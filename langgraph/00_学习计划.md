# LangGraph 7 天学习计划

> 本学习计划基于 LangGraph 0.2+ 最新版本,聚焦状态管理、持久化、人机协同、子图、多 Agent 编排等核心能力。
> 适用对象:已掌握 LangChain 基础、希望系统学习 LangGraph 的 AI/ML 学习者。

---

## 一、学习目标

经过 7 天系统学习,你将能够:

1. **理解 LangGraph 核心思想**:掌握"图即应用"的设计理念,理解为什么用图建模 Agent 工作流比传统链式调用更具优势。
2. **熟练构建状态图**:使用 `StateGraph`、`Node`、`Edge`、`State` 搭建可运行的工作流图。
3. **掌握状态管理**:使用 `TypedDict`/`Pydantic` 定义状态,理解 Reducer 机制和 `add_messages` 等内置合并函数。
4. **实现条件路由与循环**:使用条件边、`Command` 动态路由,构建带循环的 Agent 图并控制递归限制。
5. **应用持久化与记忆**:使用 `Checkpointer`、`SqliteSaver`、`PostgresSaver` 实现线程记忆、断点恢复。
6. **落地人机协同(HITL)**:掌握 `interrupt`、Tool 调用审批、动态中断,构建人在回路的应用。
7. **编排多 Agent 系统**:使用子图、Supervisor 模式、Swarm 模式完成多 Agent 协作。
8. **完成实战项目**:独立设计并实现一个多 Agent RAG / 智能客服 / 文档分析工作流。

## 二、前置知识要求

| 知识点 | 要求程度 | 说明 |
|--------|---------|------|
| Python 基础 | 必须 | 类型注解(TypedDict/Pydantic)、装饰器、异步基础 |
| LangChain 基础 | 必须 | LLM/ChatModel 调用、Prompt、OutputParser、Tool 概念 |
| LLM/Agent 概念 | 必须 | 理解 Token、上下文窗口、ReAct 模式、Tool Calling |
| 图论基础 | 建议 | 了解有向图、节点、边的基本概念即可 |
| 数据库基础 | 建议 | Day4 涉及 SQLite/PostgreSQL,了解基本 SQL 即可 |

环境准备:
- Python 3.10+
- `pip install langgraph langgraph-checkpoint-sqlite langchain-openai langchain-community`
- 设置 `OPENAI_API_KEY` 环境变量(如使用 OpenAI 模型)
- 推荐使用 VS Code / PyCharm 作为 IDE

## 三、7 天日程总览

每天预计学习时长 2-3 小时,包含:概念学习(约 45 分钟)+ 代码实操(约 60 分钟)+ 练习巩固(约 45 分钟)。

| 日期 | 主题 | 核心内容 | 产出 |
|------|------|---------|------|
| **Day1** | 基础入门 | LangGraph 简介与环境搭建、StateGraph/Node/Edge/State 核心概念、第一个图 | 可运行的最简 Agent 图 |
| **Day2** | 状态管理 | TypedDict/Pydantic State、Reducer 函数、`add_messages`、多状态合并 | 带消息历史的对话图 |
| **Day3** | 条件边与路由 | 条件边、动态路由、`Command` 路由、循环图与递归限制 | ReAct 风格循环 Agent |
| **Day4** | 持久化与记忆 | Checkpointer、SqliteSaver/PostgresSaver、线程记忆、断点与恢复 | 可记忆多轮会话的 Agent |
| **Day5** | 人机协同 | Human-in-the-loop、`interrupt`、Tool 调用审批、动态中断 | 需人工批准的 Tool Agent |
| **Day6** | 子图与多 Agent | 子图、Supervisor 模式、Swarm 模式、Agent 通信 | 多 Agent 协作系统 |
| **Day7** | 实战项目 | 多 Agent RAG / 智能客服 / 文档分析工作流 | 完整可交付项目 |

## 五、学习评估方式

### 每日评估(自测)
- 每个 Day 文件末尾配有 5-8 道练习题(选择/填空/编程题)
- 先独立完成,再对照"练习题答案"核对
- 编程题要求本地可运行,通过即视为掌握

### 阶段性评估
- **Day3 结束(中期)**:能独立写出一个带条件路由和循环的 ReAct Agent
- **Day5 结束**:能实现一个带人工审批的 Tool 调用流程
- **Day7 结束(终期)**:完成一个完整的多 Agent 实战项目,包含:
  - 至少 2 个 Agent 协作
  - 使用持久化记忆
  - 包含人机协同环节
  - 有清晰的输入输出演示

### 评估标准
| 等级 | 标准 |
|------|------|
| 优秀 | 独立完成所有练习题 + 实战项目功能完整且有创新点 |
| 良好 | 独立完成 80% 练习题 + 实战项目核心功能可用 |
| 合格 | 在提示下完成练习题 + 实战项目基本框架搭建完成 |
| 需复习 | 练习题完成率低于 60% 或实战项目无法运行 |

## 六、学习建议

1. **动手优先**:每个概念都要写代码验证,不要只看不练。
2. **逐步构建**:Day7 的实战项目可以从 Day1 开始逐步积累,每天往里加新能力。
3. **善用断点**:遇到问题先用 `print` 或 LangSmith 追踪状态流转,LangGraph 的状态可观测性很强。
4. **关注版本**:LangGraph 迭代较快,务必以本资料的 API 为准,遇到弃用警告查阅官方迁移指南。
5. **记录笔记**:建议边学边记,特别是 Reducer、Command、interrupt 这几个易混淆概念。
