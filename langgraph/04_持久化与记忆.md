> 今天我们让 Agent 拥有"记忆"。通过 Checkpointer,Agent 能记住同一对话的历史、能在崩溃后从断点恢复、能支持时间旅行(回到某个历史状态继续)。

## 二、Checkpointer 是什么

### 2.1 问题背景

回顾 Day2 的多轮对话:我们**手动**把上一轮的 messages 传给下一轮。这在真实场景下很麻烦:
- 用户可能隔几小时才来第二条消息,服务进程都重启了。
- 需要同时服务多个用户、多个对话。
- 需要支持"恢复到某一步重试"。

Checkpointer 就是解决这些问题的机制:它在**每个超级步执行后,自动把当前完整状态快照(snapshot)存到外部存储**。下次用同一个 `thread_id` 调用图时,会自动加载最新快照,接续之前的状态。

### 2.2 它持久化什么

- 完整的 State(所有字段)。
- 当前执行到哪个节点、下一步去哪。
- 消息历史、工具调用记录。
- 元数据(时间戳、步骤编号等)。

### 2.3 三种内置 Checkpointer

| Checkpointer | 存储 | 适用场景 |
|--------------|------|---------|
| `MemorySaver` | 内存(进程内字典) | 单进程测试、Demo |
| `SqliteSaver` | SQLite 文件 | 单机轻量应用、开发调试 |
| `PostgresSaver` | PostgreSQL 数据库 | 生产环境、多实例共享 |

安装:
```bash
pip install langgraph-checkpoint-sqlite       # SqliteSaver
pip install langgraph-checkpoint-postgres     # PostgresSaver
```

## 三、SqliteSaver 入门

### 3.1 最简持久化示例

```python
"""Day4 SqliteSaver 最简示例"""
import os
from typing import TypedDict, Annotated
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.checkpoint.sqlite import SqliteSaver
import sqlite3

load_dotenv()


class AgentState(TypedDict):
    messages: Annotated[list, add_messages]


def chat_node(state: AgentState) -> dict:
    llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)
    response = llm.invoke(state["messages"])
    return {"messages": [response]}


def build_graph(checkpointer):
    builder = StateGraph(AgentState)
    builder.add_node("chat", chat_node)
    builder.add_edge(START, "chat")
    builder.add_edge("chat", END)
    return builder.compile(checkpointer=checkpointer)


def main():
    # 关键:用 with 管理 SqliteSaver 生命周期
    conn = sqlite3.connect("checkpoints.db", check_same_thread=False)
    checkpointer = SqliteSaver(conn)

    graph = build_graph(checkpointer)

    # 用 thread_id 标识一个对话线程
    config = {"configurable": {"thread_id": "user-001-session-1"}}

    print("=== 第一轮 ===")
    result = graph.invoke(
        {"messages": [HumanMessage(content="我叫小明,请记住。")]},
        config=config,
    )
    print("AI:", result["messages"][-1].content)

    print("\n=== 第二轮(新进程也能记住) ===")
    # 注意:这里不再传 messages,框架会自动从 checkpointer 加载历史
    result = graph.invoke(
        {"messages": [HumanMessage(content="我刚才说叫什么?")]},
        config=config,
    )
    print("AI:", result["messages"][-1].content)


if __name__ == "__main__":
    main()
```

### 3.2 关键点解读

1. **`checkpointer=checkpointer`**:在 `compile()` 时传入,图就具备了持久化能力。
2. **`thread_id`**:通过 `config["configurable"]["thread_id"]` 指定。同一个 thread_id 下的多次调用共享同一份状态历史。不同 thread_id 互不干扰。
3. **第二次 invoke 只传新消息**:框架自动加载该 thread 的历史 messages,把新消息追加,再交给节点处理。
4. **`checkpoints.db`**:SQLite 文件,你可以用 `sqlite3` 命令查看里面的表(主要是 `checkpoints`、`checkpoints_blobs`、`checkpoints_writes`)。
5. **`check_same_thread=False`**:SqliteSaver 内部用线程,SQLite 默认禁止跨线程,需关闭这个限制。生产建议用连接池。

### 3.3 验证"跨进程记忆"

把上面的 `main()` 拆成两个脚本:

`first.py`:
```python
# ... 同上的 build_graph ...
conn = sqlite3.connect("checkpoints.db", check_same_thread=False)
graph = build_graph(SqliteSaver(conn))
graph.invoke({"messages": [HumanMessage(content="我叫小明")]},
             config={"configurable": {"thread_id": "s1"}})
```

`second.py`(单独运行):
```python
# ... 同上的 build_graph ...
conn = sqlite3.connect("checkpoints.db", check_same_thread=False)  # 同一个文件
graph = build_graph(SqliteSaver(conn))
result = graph.invoke({"messages": [HumanMessage(content="我叫什么?")]},
                      config={"configurable": {"thread_id": "s1"}})
print(result["messages"][-1].content)  # 应该回答"小明"
```

只要 `thread_id` 和 `checkpoints.db` 一致,跨进程也能续上对话。

## 四、多线程隔离

不同 `thread_id` 的状态完全隔离,这是实现多用户、多会话的基础:

```python
"""Day4 多线程隔离示例"""
import sqlite3
from typing import TypedDict, Annotated
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.checkpoint.sqlite import SqliteSaver


class AgentState(TypedDict):
    messages: Annotated[list, add_messages]


def chat_node(state: AgentState) -> dict:
    llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
    return {"messages": [llm.invoke(state["messages"])]}


conn = sqlite3.connect("multi_thread.db", check_same_thread=False)
builder = StateGraph(AgentState)
builder.add_node("chat", chat_node)
builder.add_edge(START, "chat")
builder.add_edge("chat", END)
graph = builder.compile(checkpointer=SqliteSaver(conn))

# 用户 A 的对话
config_a = {"configurable": {"thread_id": "user-A"}}
graph.invoke({"messages": [HumanMessage(content="我叫张三")]}, config=config_a)

# 用户 B 的对话(互不干扰)
config_b = {"configurable": {"thread_id": "user-B"}}
graph.invoke({"messages": [HumanMessage(content="我叫李四")]}, config=config_b)

# 用户 A 再问
r = graph.invoke({"messages": [HumanMessage(content="我叫什么?")]}, config=config_a)
print("A:", r["messages"][-1].content)  # 张三

# 用户 B 再问
r = graph.invoke({"messages": [HumanMessage(content="我叫什么?")]}, config=config_b)
print("B:", r["messages"][-1].content)  # 李四
```

## 五、查看历史快照(get_state / get_state_history)

Checkpointer 不仅存最新状态,还存**所有历史快照**,支持"时间旅行"。

### 5.1 获取当前状态

```python
config = {"configurable": {"thread_id": "s1"}}
state = graph.get_state(config)
print(state.values)         # 当前 state 字典
print(state.next)           # 下一步要执行的节点元组(空表示已结束)
print(state.config)         # 完整 config(含 checkpoint_id)
```

### 5.2 获取历史快照

```python
for snapshot in graph.get_state_history(config):
    print(snapshot.config["configurable"]["checkpoint_id"],
          snapshot.values.get("messages", [])[-1].content if snapshot.values else None,
          "next=", snapshot.next)
```

每个 snapshot 都有自己的 `checkpoint_id`,可以用来恢复到任意历史点。

### 5.3 从历史点恢复(时间旅行)

```python
# 假设某个历史 checkpoint_id 是 "abc123"
old_config = {"configurable": {"thread_id": "s1", "checkpoint_id": "abc123"}}
# 从这个点继续执行
result = graph.invoke(None, config=old_config)
```

传 `None` 作为输入,表示"不追加新输入,从该 checkpoint 继续"。

## 六、断点(interrupt_before / interrupt_after)

### 6.1 用途

有时你想在某个节点**执行前/后暂停**,以便:
- 让人工审查输入或输出(Day5 人机协同的核心)。
- 调试:看每一步的状态。
- 分批执行:先跑到这里,明天再继续。

### 6.2 用法

在 `compile` 时指定:

```python
graph = builder.compile(
    checkpointer=checkpointer,
    interrupt_before=["tools"],   # 进入 tools 节点前暂停
    interrupt_after=["agent"],    # agent 节点执行后暂停
)
```

调用 `invoke` 时,图会在指定节点前/后停下,返回当时的状态。`state.next` 会显示即将执行的节点。

要继续,用相同 `thread_id` 再次 `invoke(None, config)`:

```python
"""Day4 断点示例(基于 Day3 的 ReAct Agent)"""
import sqlite3
from typing import TypedDict, Annotated
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, AIMessage, ToolMessage
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.checkpoint.sqlite import SqliteSaver


def calculator(expression: str) -> str:
    try:
        return f"{expression} = {eval(expression, {'__builtins__': {}}, {})}"
    except (SyntaxError, NameError, TypeError, ZeroDivisionError) as e:
        return f"错误:{type(e).__name__}"


tools = [calculator]
tools_by_name = {t.__name__: t for t in tools}
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0).bind_tools(tools)


class AgentState(TypedDict):
    messages: Annotated[list, add_messages]


def agent_node(state):
    return {"messages": [llm.invoke(state["messages"])]}


def tool_node(state):
    last: AIMessage = state["messages"][-1]
    out = []
    for c in last.tool_calls:
        try:
            r = tools_by_name[c["name"]](**c["args"])
        except (KeyError, TypeError, ValueError) as e:
            r = f"错误:{type(e).__name__}"
        out.append(ToolMessage(content=str(r), tool_call_id=c["id"]))
    return {"messages": out}


def should_use_tool(state):
    last = state["messages"][-1]
    if hasattr(last, "tool_calls") and last.tool_calls:
        return "tools"
    return END


builder = StateGraph(AgentState)
builder.add_node("agent", agent_node)
builder.add_node("tools", tool_node)
builder.add_edge(START, "agent")
builder.add_conditional_edges("agent", should_use_tool)
builder.add_edge("tools", "agent")

conn = sqlite3.connect("breakpoint.db", check_same_thread=False)
graph = builder.compile(
    checkpointer=SqliteSaver(conn),
    interrupt_before=["tools"],  # 关键:执行 tools 前暂停
)

config = {"configurable": {"thread_id": "bk1"}}
print("--- 第一轮:会停在 tools 之前 ---")
graph.invoke({"messages": [HumanMessage(content="计算 123*456")]}, config=config)
state = graph.get_state(config)
print("当前 next:", state.next)  # ('tools',)
print("最后一条消息:", state.values["messages"][-1].content)
print("tool_calls:", state.values["messages"][-1].tool_calls)

print("\n--- 继续:执行 tools ---")
graph.invoke(None, config=config)  # 传 None 继续
state = graph.get_state(config)
print("执行后 next:", state.next)  # ('agent',) 或 ()
print("工具结果:", state.values["messages"][-1].content)

print("\n--- 再继续:agent 生成最终回答 ---")
result = graph.invoke(None, config=config)
print("最终:", result["messages"][-1].content)
```

### 6.3 断点的本质

`interrupt_before` 让图在进入节点前把状态存入 checkpointer 并停止。下次用相同 thread_id 调用 `invoke(None)`,从 checkpointer 加载状态,继续执行被中断的节点。这正是 Day5 人机协同的基础——暂停等人工审批,审批后继续。

## 七、PostgresSaver(生产用法)

生产环境推荐 PostgreSQL,支持多进程、多机器共享状态。

### 7.1 安装与连接

```bash
pip install langgraph-checkpoint-postgres psycopg[binary]
```

```python
from langgraph.checkpoint.postgres import PostgresSaver
import psycopg

# 同步用法
DB_URI = "postgresql://user:password@localhost:5432/langgraph_db"
with psycopg.Connection.connect(DB_URI) as conn:
    checkpointer = PostgresSaver(conn)
    checkpointer.setup()  # 首次运行创建表
    graph = builder.compile(checkpointer=checkpointer)
    # ... 使用 graph ...
```

### 7.2 异步用法

```python
import asyncio
from langgraph.checkpoint.postgres.aio import AsyncPostgresSaver
import psycopg_pool

async def main():
    pool = psycopg_pool.AsyncConnectionPool(DB_URI)
    checkpointer = AsyncPostgresSaver(pool)
    await checkpointer.setup()
    graph = builder.compile(checkpointer=checkpointer)
    # await graph.ainvoke(...)

asyncio.run(main())
```

### 7.3 选择建议

- 开发调试:`MemorySaver`(无需任何外部依赖)。
- 单机应用 / Demo:`SqliteSaver`(一个文件搞定)。
- 生产 / 多实例:`PostgresSaver`。

`MemorySaver` 用法:
```python
from langgraph.checkpoint.memory import MemorySaver
graph = builder.compile(checkpointer=MemorySaver())
# 其余用法完全一样,只是进程退出后状态丢失
```

## 八、实战:可记忆的 ReAct Agent

把 Day3 的 ReAct Agent 加上 SqliteSaver,实现"关掉程序再开,对话还在":

```python
"""Day4 可记忆的 ReAct Agent"""
import os
import sqlite3
from typing import TypedDict, Annotated
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, AIMessage, ToolMessage
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.checkpoint.sqlite import SqliteSaver

load_dotenv()


def get_weather(city: str) -> str:
    """查询天气(模拟)"""
    return {"北京": "晴 25°C", "上海": "多云 28°C", "广州": "雨 30°C"}.get(city, "无数据")


def calculator(expression: str) -> str:
    """计算表达式"""
    try:
        return f"{expression} = {eval(expression, {'__builtins__': {}}, {})}"
    except (SyntaxError, NameError, TypeError, ZeroDivisionError) as e:
        return f"错误:{type(e).__name__}"


tools = [get_weather, calculator]
tools_by_name = {t.__name__: t for t in tools}
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0).bind_tools(tools)


class AgentState(TypedDict):
    messages: Annotated[list, add_messages]


def agent_node(state):
    return {"messages": [llm.invoke(state["messages"])]}


def tool_node(state):
    last: AIMessage = state["messages"][-1]
    out = []
    for c in last.tool_calls:
        try:
            r = tools_by_name[c["name"]](**c["args"])
        except (KeyError, TypeError, ValueError) as e:
            r = f"错误:{type(e).__name__}"
        out.append(ToolMessage(content=str(r), tool_call_id=c["id"]))
    return {"messages": out}


def should_use_tool(state):
    last = state["messages"][-1]
    if hasattr(last, "tool_calls") and last.tool_calls:
        return "tools"
    return END


builder = StateGraph(AgentState)
builder.add_node("agent", agent_node)
builder.add_node("tools", tool_node)
builder.add_edge(START, "agent")
builder.add_conditional_edges("agent", should_use_tool)
builder.add_edge("tools", "agent")

conn = sqlite3.connect("react_agent.db", check_same_thread=False)
graph = builder.compile(checkpointer=SqliteSaver(conn))


def chat(thread_id: str, user_input: str) -> str:
    config = {"configurable": {"thread_id": thread_id}}
    result = graph.invoke(
        {"messages": [HumanMessage(content=user_input)]},
        config=config,
    )
    return result["messages"][-1].content


if __name__ == "__main__":
    tid = "demo-thread-1"
    print("AI:", chat(tid, "北京天气怎么样?"))
    print("AI:", chat(tid, "那上海呢?和北京差几度?"))  # 能记住上下文
    # 关掉重开,用同一个 tid 还能继续
    print("\n历史消息数:", len(graph.get_state({"configurable": {"thread_id": tid}}).values["messages"]))
```

第二次调用 `chat(tid, "那上海呢?")` 时,框架自动加载第一次的 messages 历史,LLM 能理解"那上海呢"指的是天气。

## 九、当日小结

- **Checkpointer** 在每个超级步后自动持久化完整状态,是实现记忆、恢复、时间旅行的基础。
- 三种实现:`MemorySaver`(内存)、`SqliteSaver`(SQLite 文件)、`PostgresSaver`(生产数据库)。
- **thread_id** 标识对话线程,同 thread 共享历史,不同 thread 互相隔离。
- 第二次 `invoke` 只传新消息即可,框架自动加载历史。
- **get_state / get_state_history**:查看当前和历史快照,支持时间旅行。
- **interrupt_before / interrupt_after**:在节点前后暂停,配合 `invoke(None)` 继续,是人机协同的基础。
- 生产环境用 `PostgresSaver`,开发用 `SqliteSaver`,测试用 `MemorySaver`。

## 十一、练习题答案

### 1. 答案:B
解析:Checkpointer 会根据 thread_id 自动加载历史 state,你只需要传入本轮的新输入(如新的 HumanMessage)。框架会把新输入和历史合并后交给节点。

### 2. 答案:B
解析:thread_id 是隔离单元。不同 thread_id 的状态、历史、消息互不可见。这是多用户、多会话的基础。

### 3. 答案:B
解析:`interrupt_before` 让图在进入指定节点前暂停并持久化状态。要继续执行,用相同 thread_id 调用 `invoke(None, config)`。每次到达该节点都会暂停(不只是第一次)。

### 4. 答案:`get_state`
解析:`graph.get_state(config)` 返回 `StateSnapshot` 对象,包含 `.values`(状态字典)、`.next`(下一步节点)、`.config`(含 checkpoint_id)。

### 5. 答案:`None`
解析:`invoke(None, config)` 表示"不追加新输入,从当前/指定 checkpoint 继续"。常用于断点恢复。

### 6. 答案:`Postgres`
解析:`PostgresSaver` 支持多连接、多进程共享,适合生产。`MemorySaver` 进程退出即丢,`SqliteSaver` 单文件不便多实例共享。

### 7. 参考代码

```python
"""Day4 练习题7:MemorySaver 计数器"""
import operator
from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver


class CountState(TypedDict):
    count: Annotated[int, operator.add]


def add_node(state: CountState) -> dict:
    return {"count": 1}  # 每次 +1


builder = StateGraph(CountState)
builder.add_node("add", add_node)
builder.add_edge(START, "add")
builder.add_edge("add", END)
graph = builder.compile(checkpointer=MemorySaver())

config = {"configurable": {"thread_id": "t1"}}
for i in range(3):
    graph.invoke({"count": 0}, config=config)  # 传 0 不影响累加,真正加的是节点的 1

state = graph.get_state(config)
print("count =", state.values["count"])  # 3
assert state.values["count"] == 3
```

"""Day4 练习题8:show_history 函数"""
# 假设 graph 和上文一致
from langchain_core.messages import HumanMessage, AIMessage, ToolMessage


def show_history(graph, thread_id: str) -> None:
    config = {"configurable": {"thread_id": thread_id}}
    state = graph.get_state(config)
    if not state.values or "messages" not in state.values:
        print("(无历史)")
        return
    for msg in state.values["messages"]:
        if isinstance(msg, HumanMessage):
            print(f"[用户] {msg.content}")
        elif isinstance(msg, AIMessage):
            tool_info = ""
            if hasattr(msg, "tool_calls") and msg.tool_calls:
                tool_info = f" (调用工具: {[c['name'] for c in msg.tool_calls]})"
            print(f"[AI] {msg.content}{tool_info}")
        elif isinstance(msg, ToolMessage):
            print(f"  [工具结果 {msg.name or ''}] {msg.content}")
        else:
            print(f"[{msg.type}] {msg.content}")


# 使用示例(假设已运行过 chat("t1", "北京天气?")):
