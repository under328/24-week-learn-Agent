## 一、Agent 核心概念

### 1.1 定义与架构

```
Agent = Harness(框架) + Model(大脑) + Loop(循环) + Tools(手脚) + Memory(记忆)
```

- **Agent vs Chatbot vs Workflow**：Chatbot 单轮对话；Workflow 固定流程；Agent 自主决策路径
- **核心循环**：感知 → 规划 → 行动 → 观察 → 反思
- **Harness 六大职责**：执行循环、上下文管理、工具注册调度、权限控制、错误处理、可观测性
- **为什么 Harness 是壁垒**：模型差距在缩小，同一模型换个 Harness，任务成功率可从 40% → 80%（Claude Code / Cursor / OpenHands 的核心都是 Harness 工程）

### 1.2 ReAct 框架

```
Thought → Action → Observation → Thought → ... → Final Answer
```

- **核心思想**：推理与行动交织，每步先思考再执行
- **vs CoT**：CoT 只推理不行动；ReAct 是推理 + 工具调用 + 环境反馈闭环
- **痛点**：错误累积、上下文膨胀、无反思机制 → 补 Reflection / Self-Refine

### 1.3 Function Calling 与 Tool Use

| 概念 | 说明 |
|---|---|
| Function Calling | LLM 输出结构化 JSON 调用函数，模型厂商训练支持 |
| Tool Use | 更广的工具使用能力，含 Function Calling + ReAct + 代码执行 |
| 并行调用 | 一次返回多个 `tool_call`（无依赖时可并行） |
| 工具设计 | description 是关键；Schema 用 JSON Schema；**工具超 10–15 个选择准确率下降** → 拆分 Multi-Agent |

**本质**：模型不执行函数，Harness 执行后把结果作为 observation 喂回。

### 1.4 MCP 协议

- **定义**：Model Context Protocol，Anthropic 提出的工具协议标准，"AI 的 USB-C"
- **架构**：MCP Host(Client) ← stdio / SSE → MCP Server → Tools / Resources / Prompts
- **价值**：工具一次开发、多模型通用；解耦工具实现与模型调用
- **vs Function Calling**：MCP 是协议层（标准化接口）；Function Calling 是模型能力（输出 JSON）

### 1.5 记忆系统

```
短期记忆(Working)   ← 当前对话上下文窗口
长期记忆：语义(事件) / 程序(技能) / 情景(用户画像)
外部记忆            ← 向量库 / 知识图谱
```

**记忆评分公式**：
```
Score = 0.45×similarity + 0.20×recency + 0.20×importance + 0.15×frequency
recency = e^(-λΔt), λ≈0.995 ；importance = LLM 打分 1-10
```

### 1.6 规划范式

| 范式 | 核心思想 | 代表 |
|---|---|---|
| CoT | 链式推理 | Wei 2022 |
| ToT | 树状搜索、多分支探索 | Yao 2023 |
| GoT | 图状推理，支持合并 / 回溯 | Besta 2023 |
| Plan-and-Execute | 先全局规划再逐步执行 | LangChain |
| ReWOO | 分离规划与执行，省 token | Xu 2023 |
| Reflexion | 失败后反思再重试 | Shinn 2023 |
| LATS | MCTS + LLM | Zhou 2023 |

## 二、RAG 与 Agent 结合

### 2.1 RAG 全链路

```
离线：文档 → 解析(PDF/HTML) → 清洗 → 分块 → Embedding → 向量库
在线：提问 → Query 改写 → Embedding → 检索 → Rerank → 上下文组装 → LLM 生成
```

**分块策略**：固定长度（512 token + 50–100 overlap）｜语义分块（句子相似度）｜递归分块（先段落再句子）｜父子分块（小块检索、大块供上下文）｜按标题层级

**检索增强**：HyDE（假设性文档）｜Multi-Query（多角度生成）｜Step-Back（抽象化）｜混合检索 BM25 + 向量 → RRF 融合

### 2.2 RRF 融合

```
RRF(d) = Σ 1 / (k + rank_i(d))        # k=60，实践 40–80 差异不大
```
> 真正敏感的是**召回路数**而非 k：3 路（向量 + BM25 + HyDE）反因冗余而降分，2 路常最优。

### 2.3 Agentic RAG

| 传统 RAG | Agentic RAG |
|---|---|
| 单次检索 | 迭代 / 多跳检索 |
| 固定流程 | Agent 自主决策 |
| 无路由 | 检索路由（向量 / 关键词 / 图谱） |
| 无判断 | 检索门控（是否需要检索） |

**四种增强**：检索路由 ｜ 迭代检索 ｜ 多跳推理（分解子问题）｜ 检索门控（避免无效检索）

### 2.4 GraphRAG

```
文档 → LLM 抽取实体+关系 → 知识图谱 → Leiden 社区检测 → 社区摘要
全局查询 → 社区摘要汇总 → LLM 综合｜局部查询 → 实体+邻居子图 → LLM 推理
```
- **Leiden > Louvain**：Leiden 保证社区连通性
- **适用**：全局性问题（"整个文档集的主要主题是什么"）

### 2.5 向量数据库

| 参数 | 说明 | 典型值 |
|---|---|---|
| M (HNSW) | 每层最大连接数 | 16–48 |
| efConstruction | 建索引搜索宽度 | 200–400 |
| efSearch | 查询搜索宽度 | 50–200 |
| nlist (IVF) | 聚类中心数 | √N ~ 4√N |
| nprobe | 查询探查簇数 | nlist 的 1%–5% |

**选型**：Milvus（亿级、分布式）｜Qdrant（Rust 高性能、过滤强）｜Chroma（轻量原型）｜pgvector（已有 PG、小规模）｜Elasticsearch（已有 ES、混合检索）

### 2.6 Context Engineering

- **Lost in the Middle**：长上下文中间位置信息易被忽略（U-shaped attention）
- **上下文压缩**：LLMLingua 压缩 prompt 2–20x
- **Token 预算分配**：System 10% + 检索上下文 40% + 对话历史 30% + 输出空间 20%
- **策略**：相关优先 + 最新优先 + 摘要替代旧历史

### 2.7 RAG 评估

| 指标 | 含义 |
|---|---|
| Faithfulness | 答案中可被上下文支撑的陈述占比 |
| Answer Relevancy | 答案反向生成问题的相似度 |
| Context Precision | 相关文档在检索结果中的排名加权 |
| Context Recall | Ground truth 可被上下文支撑的占比 |

**检索指标**：Recall@K、MRR、NDCG

## 三、框架与系统设计

### 3.1 LangChain vs LangGraph

| 维度 | LangChain | LangGraph |
|---|---|---|
| 抽象 | Chain 链式 | StateGraph 图状 |
| 状态 | 无状态 / 线性 | 显式状态管理（Reducer） |
| 循环 | 不支持 | 支持 cycles |
| 适用 | 简单 RAG / 链 | Agent / 多步 / 多 Agent |
| 持久化 | Memory | Checkpointing |

**LangGraph 要点**：`StateGraph` / `add_conditional_edges` / `Command(goto=, update=)` 动态路由 / `recursion_limit` 默认 25 / `interrupt` + `Command(resume=)` 人机协同 / Checkpointer（MemorySaver / SqliteSaver / PostgresSaver）+ `thread_id` 隔离 / `get_state_history` 时间旅行

### 3.2 框架横评

| 框架 | 定位 | 优势 | 劣势 |
|---|---|---|---|
| LangChain | 全家桶 | 生态大、组件全 | 抽象重、版本碎 |
| LlamaIndex | RAG 专精 | 数据连接强 | Agent 弱于 LC |
| AutoGen | Multi-Agent | 对话式协作 | API 变动大 |
| CrewAI | 角色扮演 | 简单直观 | 灵活性不足 |
| Dify | 低代码 | 可视化、部署快 | 定制受限 |

### 3.3 Multi-Agent 协作模式

```
1. Hierarchical(层级)  CEO → Manager → Worker
2. Sequential(串行)    A → B → C → D
3. Parallel(并行)      A,B,C 同时执行 → 汇总
4. Debate(辩论)        A ↔ B 多轮辩论 → 裁判
5. Network(网络)       任意 Agent 可互相通信
```
**通信三机制**：共享 State ｜ 消息传递 ｜ 黑板模式
**必答**：角色分工、终止条件、防无限循环、冲突去重合并、质量门控回退

### 3.4 评测与可观测性

**评测基准**：AgentBench、GAIA、SWE-bench、τ-bench

**Tracing 三层**：Trace（一次完整请求）→ Span（LLM 调用 / 工具调用 / 检索）→ Event（细粒度事件）

**关键指标**：任务成功率、步骤效率、平均 Token / 成本、P50 / P99 延迟
**工具**：LangSmith、Langfuse、Phoenix、Prometheus + Grafana

### 3.5 Agent 安全

**OWASP LLM Top 10 核心**：Prompt Injection ｜ Insecure Output Handling ｜ Training Data Poisoning ｜ Model DoS ｜ Supply Chain

**防御**：
- Prompt Injection → 分离系统指令与用户输入、结构化 prompt、输入过滤
- 工具权限 → 最小权限、白名单、高危操作人工审批
- 输出安全 → Schema 校验、沙箱执行代码

## 八、LLM 与 Transformer（Day34）

### 8.1 架构

```
Embedding + Position Encoding
→ Self-Attention(Q=XWq, K=XWk, V=XWv)
→ Multi-Head(并行 h 头 → concat → Wo)
→ Add & Norm → FFN → Add & Norm     × N 层
→ Output(LM Head)
```

### 8.2 Self-Attention

```
Attention(Q,K,V) = softmax(QK^T / √dk) × V
# 除以 √dk：dk 大时点积方差大，softmax 进饱和区梯度趋近 0
# 除以 √dk 使方差稳定为 1，梯度健康
```

### 8.3 位置编码

| 方法 | 原理 | 优势 |
|---|---|---|
| Sinusoidal | sin/cos 不同频率 | 可外推、无需学习 |
| Learned | 可学习位置向量 | 灵活但不可外推 |
| RoPE | 旋转矩阵编码相对位置 | 外推好、主流（LLaMA） |
| ALiBi | attention bias 按距离衰减 | 极简、外推好 |

### 8.4 训练流程

```
Pre-training → SFT(指令微调) → RLHF(Reward Model + PPO) 或 DPO(无需 RM)
```

### 8.5 微调与推理优化

- **微调参数量**：Full FT 100% ｜ LoRA 0.1–1% ｜ QLoRA 0.1–1%（4bit 基座）｜ Adapter 1–5% ｜ Prefix Tuning <1%
- **推理优化收益**：KV-Cache 2–4x ｜ Flash Attention 2–3x ｜ PagedAttention 显存利用率↑ ｜ 量化 INT8/INT4 显存减半 + 2x ｜ 投机解码 1.5–2x ｜ Continuous Batching 吞吐 5–10x

### 9.5 项目讲述节奏（BPARR，2–3 分钟）

```
30s  Background  背景：谁、做什么、遇到什么问题
1min Problem     问题：带量化，如"召回率从 72% 掉到 41%"
2min Action      方案：讲过程不只讲结论，2–3 个核心技术决策
30s  Result      结果：改前 vs 改后对比

```

- **5 层追问漏斗**：What（表达）→ How（细节真实性）→ Why（选型 trade-off）→ What if（架构边界）→ Reflect（反思成长）
- **每个数字备好三件套**：测试集来源 + 标注方式 + 指标定义
- **自查标准**：具体问题 + 量化结果 + 反思沉淀 = 满分；缺反思 -30%；无量化 -20%；只讲理论 -50%

## 十、关键公式速查

```
Attention(Q,K,V) = softmax(QK^T / √dk) × V
RRF(d)           = Σ 1/(k + rank_i(d)),  k=60
记忆评分          = 0.45×sim + 0.20×recency + 0.20×importance + 0.15×frequency
recency          = e^(-λΔt),  λ≈0.995
DCG@K            = Σ rel_i / log2(i+1) ;  NDCG@K = DCG@K / IDCG@K
交叉熵            = -Σ y_i × log(p_i)
LoRA             = W₀ + BA,  B∈R^(d×r), A∈R^(r×d), r << d
A/B 样本量        = 16 × σ² / Δ²   (近似, α=0.05, power=0.8)
```
