## 易错点提醒

1. **不要把 Agent 当万能解**: 美团面试官反感"用 Agent 解决一切",要明确 Agent 与运筹、规则、传统 ML 的边界。Agent 擅长复杂推理和跨系统联动,不擅长毫秒级实时决策和海量数据处理。

2. **不要忽视 ROI**: 美团特别看重成本收益。讲方案时一定要给量化指标(解决率、成本、CSAT),不要只讲技术不讲业务价值。LLM 调用贵,简单问题不要上 LLM。

3. **不要忽视灰度方案**: 美团/蚂蚁都重工程,会追问"怎么上线?""出问题怎么办?"。必须讲清楚灰度策略(用户哈希 + 业务线 + 地域)、监控指标、回滚预案。

4. **金融场景绝不能让 LLM 直答数字**: 金额、利率、订单状态必须以系统数据为准,LLM 只做组织和表达。幻觉在金融场景是致命的,要讲清楚数据走 API + 引用溯源 + 置信度兜底。

5. **不要忽视合规审查**: 蚂蚁必考合规。回答金融 Agent 设计时,必须主动讲:违规词清单、风险提示、持牌范围、可追溯、可回放。不讲合规基本挂。

6. **不要混淆"中台"和"大一统"**: 智能客服中台不是把所有业务线揉在一起,而是"共享核心能力 + 业务线隔离"。要讲清楚命名空间隔离、数据隔离、独立灰度。

7. **不要忽视人工协作**: Agent 不能 100% 自助,必须设计好转人工策略(情绪、置信度、高风险、用户主动)和上下文传递(摘要 + 画像 + 历史)。坐席辅助(推荐话术、自动小结)也是加分项。

8. **不要忽视多模态**: 美团场景多模态很重要(菜单图 OCR、商家视频、用户上传图)。讲商家 RAG 时要提多模态处理,不能只讲文本。

9. **不要忽视数据脱敏**: 金融场景敏感数据脱敏是基础。身份证、手机、银行卡、金额都要脱敏,LLM 不接触原始数据。这是合规底线,不能漏。

10. **不要忘记价值观(蚂蚁)**: 蚂蚁有阿里价值观面,会问"挑战/合作/客户第一"的故事。准备 2-3 个 STAR 故事,讲具体不喊口号。美团价值观相对轻松,但也要务实不浮夸。
