## 易错点提醒(10 个)

1. **误区:华为只做政企** —— 错。华为有终端(手机 / 车机 / 鸿蒙)、云、政企三大 BG,Agent 岗位分布广泛。
2. **误区:盘古 = 通用大模型** —— 错。盘古战略是"行业大模型",不做 ChatGPT 式通用聊天,这是和互联网公司的关键差异。
3. **误区:昇腾 = 国产 GPU** —— 不准确。昇腾是 NPU(神经网络处理器),架构和 GPU 不同,有 Cube 矩阵单元,编程模型用 Ascend C,不是 CUDA。
4. **误区:端侧 Agent 就是小模型** —— 错。端侧 Agent 是"小模型 + 工具 + 缓存 + 端云协同"的系统,不是单纯部署小模型。
5. **误区:私有化 = 简单部署** —— 错。私有化涉及硬件上架、信创适配、等保测评、客户培训,交付周期 3-6 个月。
6. **误区:国密 = 简单换算法** —— 错。国密涉及密钥管理、证书体系、硬件密码机,合规要求复杂。
7. **误区:鸿蒙 = Android 替代** —— 不准确。鸿蒙的核心差异化是"分布式软总线 + 元服务",不是简单的 OS 替换。
8. **误区:ModelArts = 训练平台** —— 不全面。ModelArts 是全流程平台(数据 + 训练 + 部署 + 运维),Studio 还做 Agent 可视化编排。
9. **误区:华为不看重算法创新** —— 错。2012 实验室 / 诺亚方舟看重顶会论文和算法创新,只是更强调"能落地的算法"。
10. **误区:华为面试只问八股** —— 错。华为系统设计题占比很高(尤其二面),且常带华为业务色彩(金融 Agent / 政企合规)。
