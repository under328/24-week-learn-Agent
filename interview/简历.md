## Agent 项目经历

### 1. CodeAgentHarness —— 编程智能体（华为内源平台 · 独立设计开发）
`TypeScript / Node.js · 单 Agent ReAct 架构 · 2025.⬜ – 2026.10`

团队「改代码 + 代码审查」高度依赖人工，规则类工具无法理解业务语义与逻辑缺陷。目标是做一个可被其他团队复用的编程智能体，把「定位代码 → 修改 → 自审 → 出 diff」链路自动化。**1 人独立完成方案设计、架构搭建、编码实现与内源发布。**

- **Harness 运行框架**：用 Node.js + TypeScript 从零实现单 Agent ReAct 循环——模型只负责推理，Harness 负责工具注册与调度、上下文组装、错误恢复、权限管控与全链路日志；不用现成框架以换取可控性
- **工具层**：封装文件读写、代码检索、diff 生成、Shell 执行、Git 操作；用 TS 类型 + JSON Schema 自动生成工具签名，保证模型调用参数合法
- **上下文工程**：按文件 / 符号粒度召回相关代码而非整仓塞入，动态裁剪上下文预算，解决大仓库超窗与噪声干扰
- **自动改代码 + 自动审查**：读码 → 定位改动点 → 生成补丁 → 输出 diff，人工确认后落盘，可追溯可回滚；审查链路按「风格 → 逻辑缺陷 → 安全风险」分层输出结构化意见并附严重度分级与修复建议
- **安全可控**：工具白名单 + 读写权限分离；Shell 命令超时与沙箱约束；敏感操作（删除、批量改写）强制人工确认，避免越权改动代码库
- **成果**：在华为内源平台发布并开放给内部团队，被 **⬜【待补：N 个】业务团队** 试用接入。工程实践证明：同一模型下补齐上下文管理与错误恢复后任务完成率显著提升——**生产级 Agent 的壁垒在 Harness，不在模型**

### 3. 智能客服 Agent —— RAG + HITL 人机协同（自驱实战 · LangGraph）
`Python · LangGraph · interrupt · SqliteSaver`

- **结构化路由**：`bind_tools` + `tool_choice` 强制模型输出路由枚举，分发到 `rag_agent` / `ticket_agent` / `human_agent`；`Command(goto=..., update=...)` 跳转，工人完成后回流 Supervisor 形成可控循环
- 检索命中即答；检索不到时不编造，自动转入工单流程创建工单
- **HITL 审批**：退款、投诉等敏感操作在节点内 `interrupt()` 暂停并保留完整状态，人工审批后 `Command(resume="approve")` 恢复——Agent 提议、人拍板
- **持久化隔离**：SqliteSaver + 按用户划分 `thread_id`，实现跨轮记忆与多用户会话互不串扰；4 类场景端到端验证

### 4. 企业知识库 RAG Agent 与上线工程（自驱实战）
`Python · ChromaDB · FastAPI · Docker`

- **检索链路**：四种切分策略 → ChromaDB 索引 → 混合检索（向量 + 关键词）+ **RRF 融合（k=60）** → Query 改写与相邻块上下文扩展 → **增量索引**（md5 指纹，仅重建变更文档）
- **评测闭环**：基于 LLM-as-Judge 实现 Faithfulness / Answer Relevance / Context Relevance / Completeness 四维打分，用固定评测集对比改动前后，而非凭感觉判断
- **服务化与降本**：FastAPI 暴露 `/agent`（返回路由 / Token / 缓存命中 / 端到端延迟）与 `/health`；SSE 流式输出 + Nginx 关闭 `proxy_buffering`；LRUCache（max_size=200、ttl=600）+ 命中率统计；Docker 多阶段构建 + Compose（api / redis / nginx）+ 限流 429 + `X-API-Key` 鉴权
- **测试**：pytest 单元 / 集成 / 回归测试 + 性能回归阈值 + Golden Set 报告
- 同一需求手写版约 500 行、LangChain 重构版约 200 行（↓60%），据此形成「何时用框架、何时自研」的取舍判断
