# LangChain 7 天学习计划

> 基于 LangChain v0.3+ 版本(基于 langchain-core,整合 langchain-community,推荐使用 LangSmith)
> 适用读者:AI/ML 学习者、HarmonyOS 移动开发者、华为员工、对本地 AI/RAG 工具感兴趣的同学
> 撰写语言:中文

---

## 一、学习目标

通过 7 天的系统学习,你将能够:

1. **理解 LangChain 核心架构**:掌握 langchain-core、langchain-community、langchain-openai 等包的分工与协作关系
2. **熟练使用 LCEL 表达式语言**:使用 `prompt | model | parser` 链式语法构建应用,取代旧的 `LLMChain` 等类
3. **掌握 Chat Model 与 Prompt 工程**:使用 `ChatOpenAI` 等 Chat Model,结合 `ChatPromptTemplate` 构建对话
4. **构建 RAG 应用**:从文档加载、切分、嵌入、向量存储到检索,完整实现 RAG 流程
5. **理解 Agent 与 Tools**:使用最新的 Agent 架构,让 LLM 自主调用工具完成任务
6. **完成实战项目**:搭建一个完整的本地 RAG 知识库问答系统

---

## 二、前置知识要求

| 知识点 | 要求程度 | 说明 |
|--------|---------|------|
| Python 基础 | 必需 | 函数、类、装饰器、异步(async/await)、类型注解 |
| pip 包管理 | 必需 | 安装、虚拟环境(venv/conda) |
| LLM 概念 | 推荐 | 了解 GPT、Token、上下文窗口、Temperature 等基本概念 |
| 向量与嵌入 | 推荐 | 了解向量相似度、Embedding 的基本概念 |
| REST API | 推荐 | 了解 HTTP 请求、API Key 认证 |

**环境准备**:
- Python 3.10+ (推荐 3.11 或 3.12)
- 一个可用的 LLM API(OpenAI / 通义千问 / 智谱 / DeepSeek 等均可,本教程以 OpenAI 兼容接口为例)
- 设置环境变量 `OPENAI_API_KEY`(或对应厂商的 API Key)

## 三、7 天日程总览

| 天数 | 主题 | 学习时长 | 关键产出 |
|------|------|----------|----------|
| Day 1 | 基础入门:简介与环境搭建、LLM/ChatModel 调用、Prompt Templates | 2-3 小时 | 跑通第一个 LangChain 程序 |
| Day 2 | Output Parsers、消息类型、Prompt 组合(LCEL) | 2-3 小时 | 实现结构化输出 |
| Day 3 | Chains 与 LCEL 表达式语言、Runnable 接口 | 2-3 小时 | 用 LCEL 构建复杂链 |
| Day 4 | Memory 与历史对话、ConversationBufferMemory 等 | 2-3 小时 | 实现带记忆的对话机器人 |
| Day 5 | Document Loaders 与 Text Splitters、Embeddings | 2-3 小时 | 文档加载与切分脚本 |
| Day 6 | Vector Stores 与 Retriever、RAG 基础 | 2-3 小时 | 搭建向量检索 demo |
| Day 7 | Agents 与 Tools、完整 RAG 项目实战 | 3 小时 | 完整 RAG 知识库问答系统 |

每天建议节奏:
- 30 分钟:阅读核心概念讲解
- 60-90 分钟:动手敲代码示例并运行
- 30 分钟:完成练习题并对照答案
- 15 分钟:回顾当日小结

## 五、学习评估方式

### 每日评估(自测)
- 每个 Day 文件末尾附带 5-8 道练习题(选择/填空/编程题)

## 六、学习建议

1. **动手优先**:每段代码都要亲自敲一遍并运行,不要只看不练
2. **善用 LangSmith**:从 Day 1 就开启 LangSmith 追踪,观察每一步的输入输出,加速调试
3. **关注版本**:LangChain 迭代很快,遇到报错先检查版本是否匹配,本教程基于 v0.3+
4. **国内可访问性**:若 OpenAI 访问不便,可使用通义千问/智谱/DeepSeek 的 OpenAI 兼容接口,代码几乎无需改动
5. **循序渐进**:每天内容有前后依赖,建议按顺序学习,不要跳读
6. **记录笔记**:建议用 Markdown 记录每天的学习笔记和踩坑经验
