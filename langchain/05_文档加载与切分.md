## 二、核心概念讲解

### 2.1 RAG 流程概览

RAG(Retrieval-Augmented Generation,检索增强生成)是让 LLM 基于**外部知识**回答问题的技术。完整流程:

```
原始文档 -> [Document Loader 加载] -> [Text Splitter 切分] -> [Embedding 嵌入] -> [Vector Store 存储]
                                                                              |
用户提问 -> [Embedding 嵌入] -> [Vector Store 检索] -> 相关片段 + 问题 -> [LLM 生成] -> 答案
```

今天我们学习前三步:**加载、切分、嵌入**。Day 6 学习检索,Day 7 完成完整 RAG。

### 2.2 为什么需要切分

LLM 的上下文窗口有限(即使 128K 也有上限),而且:
- **太长的文档**:LLM 容易"遗忘"中间部分(lost in the middle 问题)
- **检索精度**:RAG 需要检索相关片段,如果文档太长,检索到的不够精准
- **成本**:长文档嵌入和生成成本高

因此需要把长文档切成**合适大小的片段(chunk)**,典型大小 500-1000 字符。

### 2.3 Document Loaders

Document Loader 负责把各种格式的文件加载成 LangChain 的 `Document` 对象:

```python
class Document:
    page_content: str    # 文本内容
    metadata: dict       # 元数据(来源、页码等)
```

常用 Loaders(在 `langchain_community.document_loaders` 中):

| Loader | 用途 | 安装 |
|--------|------|------|
| `TextLoader` | 加载纯文本(.txt) | 无需额外安装 |
| `MarkdownLoader` | 加载 Markdown | `pip install unstructured` |
| `PyPDFLoader` | 加载 PDF | `pip install pypdf` |
| `WebBaseLoader` | 加载网页(BeautifulSoup) | `pip install beautifulsoup4` |
| `DirectoryLoader` | 批量加载目录 | 无需额外安装 |
| `CSVLoader` | 加载 CSV | 无需额外安装 |

### 2.4 Text Splitters

Text Splitter 负责把长文档切成片段。常用切分器:

| Splitter | 策略 | 适用场景 |
|----------|------|----------|
| `RecursiveCharacterTextSplitter` | 递归按分隔符切分(优先段落,再句子) | **通用推荐** |
| `CharacterTextSplitter` | 按单一分隔符切分 | 简单场景 |
| `TokenTextSplitter` | 按 Token 数切分 | 精确控制 Token |
| `MarkdownHeaderTextSplitter` | 按 Markdown 标题切分 | Markdown 文档 |
| `RecursiveJsonSplitter` | 切分 JSON | 结构化数据 |

**核心参数**:
- `chunk_size`:每个片段的最大大小(字符数或 Token 数)
- `chunk_overlap`:相邻片段的重叠量(保证上下文连贯)

**为什么需要 overlap?** 如果切片恰好把一个完整句子从中间切断,检索时可能丢失关键信息。重叠(如 50-200 字符)让相邻片段有部分共享内容,缓解这个问题。

### 2.5 Embeddings(嵌入)

Embedding 是把文本转成**浮点数向量**的技术,使得**语义相似的文本在向量空间中距离更近**。

```
"猫是一种宠物" -> [0.12, -0.34, 0.56, ..., 0.78]  (1536维)
"狗是一种宠物" -> [0.15, -0.31, 0.52, ..., 0.75]  (语义相近,向量也相近)
"今天股市大跌" -> [-0.43, 0.67, -0.12, ..., 0.09] (语义不同,向量差异大)
```

常用 Embedding 模型:

| 模型 | 来源 | 安装 |
|------|------|------|
| `OpenAIEmbeddings` | OpenAI text-embedding 系列 | `langchain-openai` |
| `DashScopeEmbeddings` | 阿里通义 | `langchain-community` |
| `HuggingFaceEmbeddings` | HuggingFace 本地模型 | `langchain-huggingface` |

**关键点**:嵌入和检索必须用**同一个模型**,否则向量维度和语义空间不匹配。

### 3.5 RecursiveCharacterTextSplitter 递归切分

```python
"""
Day5 示例 4:递归字符切分器(最常用)
"""
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 长文本示例
long_text = """
第一章 LangChain 概述

LangChain 是一个用于构建大语言模型应用的开源框架。它提供了丰富的组件,
包括模型接口、Prompt 模板、链、记忆和检索器。LangChain 支持多种大模型,
如 OpenAI GPT 系列、Anthropic Claude 系列等。

第二章 核心概念

2.1 模型接口
LangChain 提供统一的模型接口,支持 LLM 和 Chat Model 两种类型。
推荐使用 Chat Model,因为它支持多轮对话和消息类型。

2.2 Prompt 模板
Prompt 模板可以参数化地生成 Prompt,支持变量替换和消息组合。
ChatPromptTemplate 专为 Chat Model 设计,可以生成消息列表。

2.3 链与 LCEL
LCEL 是 LangChain 的表达式语言,用管道符连接组件。
它支持流式输出、批量处理和异步调用。

第三章 RAG 检索增强生成

RAG 是一种结合检索和生成的技术。它先从知识库中检索相关文档片段,
然后将这些片段作为上下文传给 LLM,让 LLM 基于上下文回答问题。
RAG 能有效解决 LLM 知识过时和幻觉问题。

第四章 Agent 代理

Agent 是能自主调用工具的 LLM。它根据用户需求,决定调用哪些工具、
按什么顺序调用,并把工具返回的结果整合成最终答案。
"""

# 创建切分器
splitter = RecursiveCharacterTextSplitter(
    chunk_size=200,        # 每个片段最大 200 字符
    chunk_overlap=50,      # 相邻片段重叠 50 字符
    separators=["\n\n", "\n", "。", " ", ""],  # 分隔符优先级
)

chunks = splitter.split_text(long_text)

print(f"切分前长度: {len(long_text)} 字符")
print(f"切分后片段数: {len(chunks)}")
print()

for i, chunk in enumerate(chunks):
    print(f"=== 片段 {i+1} (长度 {len(chunk)}) ===")
    print(chunk)
    print()
```

### 3.7 Embeddings 嵌入

```python
"""
Day5 示例 6:使用 OpenAI Embeddings
"""
from langchain_openai import OpenAIEmbeddings

# 初始化嵌入模型
# text-embedding-ada-002 是 OpenAI 经典嵌入模型
# text-embedding-3-small 是新版,更便宜
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 嵌入单条文本
text = "LangChain 是一个 LLM 框架"
vector = embeddings.embed_query(text)

print(f"文本: {text}")
print(f"向量维度: {len(vector)}")
print(f"向量前5维: {vector[:5]}")

# 嵌入多条文本(批量)
texts = [
    "LangChain 是一个 LLM 框架",
    "今天天气真好",
    "Python 是一种编程语言",
]
vectors = embeddings.embed_documents(texts)

print(f"\n批量嵌入 {len(texts)} 条文本")
print(f"每条向量维度: {len(vectors[0])}")

# 计算余弦相似度(需安装 numpy: pip install numpy)
import numpy as np

def cosine_similarity(v1, v2):
    """计算两个向量的余弦相似度"""
    arr1, arr2 = np.array(v1), np.array(v2)
    return np.dot(arr1, arr2) / (np.linalg.norm(arr1) * np.linalg.norm(v2))

sim_01 = cosine_similarity(vectors[0], vectors[1])
sim_02 = cosine_similarity(vectors[0], vectors[2])
sim_12 = cosine_similarity(vectors[1], vectors[2])

print(f"\n相似度对比:")
print(f"  'LLM 框架' vs '天气': {sim_01:.4f}")
print(f"  'LLM 框架' vs '编程语言': {sim_02:.4f}")
print(f"  '天气' vs '编程语言': {sim_12:.4f}")
```

### 3.8 综合示例:文档加载到嵌入完整流程

```python
"""
Day5 示例 7:完整流程 - 加载 -> 切分 -> 嵌入
"""
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings

# 1. 创建测试文档
article = """
人工智能的发展历程

人工智能(AI)的概念最早在 1956 年的达特茅斯会议上被提出。
早期的研究集中在符号推理和专家系统,但由于计算能力限制,
经历了多次"AI 寒冬"。

深度学习的崛起

2012 年,AlexNet 在 ImageNet 竞赛中大幅领先,标志着深度学习时代的到来。
GPU 的普及和大数据的积累让训练大型神经网络成为可能。

大语言模型时代

2017 年,Google 提出 Transformer 架构,奠定了现代大语言模型的基础。
随后 GPT 系列、BERT、LLaMA 等模型相继问世,推动了 AI 的广泛应用。

RAG 与 Agent

RAG(检索增强生成)通过检索外部知识库来增强 LLM 的回答能力。
Agent 则让 LLM 能自主调用工具,完成复杂任务。
这两项技术是当前 LLM 应用的核心方向。
"""

with open("ai_article.txt", "w", encoding="utf-8") as f:
    f.write(article)

# 2. 加载文档
loader = TextLoader("ai_article.txt", encoding="utf-8")
docs = loader.load()
print(f"步骤1 - 加载: {len(docs)} 个文档, {len(docs[0].page_content)} 字符")

# 3. 切分
splitter = RecursiveCharacterTextSplitter(
    chunk_size=150,
    chunk_overlap=30,
    separators=["\n\n", "\n", "。", " "],
)
chunks = splitter.split_documents(docs)
print(f"步骤2 - 切分: {len(chunks)} 个片段")

# 4. 嵌入
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
texts = [chunk.page_content for chunk in chunks]
vectors = embeddings.embed_documents(texts)
print(f"步骤3 - 嵌入: {len(vectors)} 个向量, 每个维度 {len(vectors[0])}")

# 5. 查看切分结果
print("\n=== 切分片段预览 ===")
for i, chunk in enumerate(chunks):
    print(f"\n片段 {i+1} (长度 {len(chunk.page_content)}):")
    print(chunk.page_content)

# 6. 测试语义检索:用一个问题找最相似的片段
query = "Transformer 是什么时候提出的?"
query_vector = embeddings.embed_query(query)

import numpy as np

def cosine_similarity(v1, v2):
    arr1, arr2 = np.array(v1), np.array(v2)
    return float(np.dot(arr1, arr2) / (np.linalg.norm(arr1) * np.linalg.norm(arr2)))

similarities = [cosine_similarity(query_vector, v) for v in vectors]
best_idx = int(np.argmax(similarities))

print(f"\n=== 语义检索测试 ===")
print(f"问题: {query}")
print(f"最相似片段(相似度 {similarities[best_idx]:.4f}):")
print(chunks[best_idx].page_content)
```

## 四、当日小结

| 要点 | 内容 |
|------|------|
| RAG 流程 | 加载 -> 切分 -> 嵌入 -> 存储 -> 检索 -> 生成 |
| Document 对象 | 包含 `page_content`(文本)和 `metadata`(元数据) |

| chunk_size / chunk_overlap | 控制片段大小和重叠,典型 500-1000 字符,重叠 50-200 |
| Embeddings | 把文本转向量,语义相似的文本向量距离更近 |
| 嵌入一致性 | 嵌入和检索必须用同一个模型 |
| 余弦相似度 | 衡量两个向量方向的相似程度,范围 -1 到 1 |

## 六、练习题答案

### 1. 答案:C
**解析**:RAG 文档处理流程是:先用 Document Loader **加载**原始文档,再用 Text Splitter **切分**成片段,最后用 Embedding 模型**嵌入**成向量。Day 6 会学习存储和检索。

### 2. 答案:B
**解析**:`chunk_overlap` 让相邻片段有部分重叠内容,避免句子被从中间切断导致语义丢失。典型值 50-200 字符。

### 3. 答案:B
**解析**:LangChain 的 `Document` 对象有 `page_content`(文本内容,字符串)和 `metadata`(元数据,字典,如来源、页码)两个字段。

### 4. 答案:C
**解析**:嵌入和检索必须用同一个模型,否则向量维度和语义空间不匹配,相似度计算无意义。语义相似的文本向量距离更**近**(不是更远),嵌入支持多种语言。

### 5. 答案:`\n\n`(两个换行符,表示段落)
**解析**:默认 separators 是 `["\n\n", "\n", " ", ""]`,优先按段落切,段落太大再按行,再按空格,最后按字符。

### 6. 答案:`-1`、`1`
**解析**:余弦相似度衡量向量方向相似程度,范围 -1(方向相反)到 1(方向相同),0 表示正交(不相关)。文本嵌入的相似度通常在 0 到 1 之间。

"""
练习题 8:语义搜索
"""
import numpy as np
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings

# 复用第7题的文档
loader = TextLoader("harmonyos.txt", encoding="utf-8")
docs = loader.load()
splitter = RecursiveCharacterTextSplitter(chunk_size=100, chunk_overlap=20)
chunks = splitter.split_documents(docs)

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
texts = [c.page_content for c in chunks]
doc_vectors = embeddings.embed_documents(texts)

def cosine_similarity(v1, v2):
    arr1, arr2 = np.array(v1), np.array(v2)
    return float(np.dot(arr1, arr2) / (np.linalg.norm(arr1) * np.linalg.norm(arr2)))

# 3 个查询
queries = [
    "HarmonyOS 支持什么设备?",
    "ArkTS 是什么语言?",
    "怎么开发 UI 界面?",
]

for query in queries:
    query_vector = embeddings.embed_query(query)
    similarities = [cosine_similarity(query_vector, v) for v in doc_vectors]
    best_idx = int(np.argmax(similarities))

    print(f"问题: {query}")
    print(f"最相关片段(相似度 {similarities[best_idx]:.4f}):")
    print(f"  {chunks[best_idx].page_content}")
    print()
