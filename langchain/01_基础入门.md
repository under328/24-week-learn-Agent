## 二、核心概念讲解

### 2.1 LangChain 是什么

LangChain 是一个用于构建 LLM(大语言模型)应用的开源框架。它提供了一套统一的接口,让你能够:

- **连接各种 LLM**:OpenAI、Anthropic、通义千问、智谱、DeepSeek 等,切换模型只需改一行代码
- **管理 Prompt**:模板化、复用、组合 Prompt
- **链接组件**:把 Prompt、Model、Parser 像管道一样串联起来(LCEL)
- **接入数据**:加载文档、切分、嵌入、向量检索(RAG)
- **调用工具**:让 LLM 自主决定调用哪些工具(Agent)

简单说,LangChain 就是 LLM 应用的"脚手架",让你不必从零造轮子。

### 2.2 LangChain v0.3+ 包结构

LangChain 在 v0.3 进行了重大重构,拆分为多个独立包:

| 包名 | 作用 | 安装命令 |
|------|------|----------|
| `langchain-core` | 核心抽象(Runnable、PromptTemplate 等),无第三方依赖 | `pip install langchain-core` |
| `langchain` | 主包,提供 Chains、Agents 等高层抽象 | `pip install langchain` |
| `langchain-community` | 社区集成(各种文档加载器、向量库、工具) | `pip install langchain-community` |
| `langchain-openai` | OpenAI 官方集成 | `pip install langchain-openai` |
| `langchain-experimental` | 实验性功能 | 按需安装 |

**关键变化(v0.3 相比旧版)**:
- 社区集成从 `langchain` 移到了 `langchain-community`
- 各厂商集成独立成包(如 `langchain-openai`、`langchain-anthropic`)
- **推荐使用 LCEL**(LangChain Expression Language)而非旧的 `LLMChain`、`ConversationChain` 等类
- 旧的 `llms` 模块(如 `OpenAI` 类)已弃用,统一使用 `chat_models`(如 `ChatOpenAI`)

### 2.3 LLM vs Chat Model

LangChain 中有两类模型接口:

- **LLM**(已不推荐):输入字符串,输出字符串。如旧的 `OpenAI` 类
- **Chat Model**(推荐):输入消息列表,输出消息。如 `ChatOpenAI` 类

现在几乎所有的主流模型都是对话型的,因此**统一使用 Chat Model**。Chat Model 的输入输出都是"消息"对象。

### 2.4 消息类型

Chat Model 接受的消息类型(都在 `langchain_core.messages` 中):

| 消息类 | 角色 | 说明 |
|--------|------|------|
| `SystemMessage` | system | 设定 AI 的行为/人设 |
| `HumanMessage` | user | 用户的输入 |
| `AIMessage` | assistant | AI 的回复 |
| `ToolMessage` | tool | 工具调用的返回结果 |

示例:一个对话的消息列表可能是:
```
[SystemMessage("你是一个翻译助手"),
 HumanMessage("把'你好'翻译成英文"),
 AIMessage("Hello")]
```

### 2.5 Prompt Templates

Prompt 模板让你可以参数化地生成 Prompt,而不是硬编码字符串。

- **`PromptTemplate`**:用于普通 LLM(字符串输入输出),生成一个字符串
- **`ChatPromptTemplate`**:用于 Chat Model,生成一个消息列表

`ChatPromptTemplate` 的常用创建方式:

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个{role}。"),
    ("human", "{question}"),
])
```

这里 `("system", "...")` 是元组简写,等价于 `SystemMessage(content="...")`。`{role}` 和 `{question}` 是占位符,后续用 `prompt.invoke({"role": "翻译助手", "question": "你好"})` 填充。

### 3.1 环境搭建

**第一步:创建虚拟环境并安装依赖**

```bash
# 创建虚拟环境
```

```bash
# 设置 OpenAI API Key
```

```python
    model="deepseek-chat",
```

### 3.2 第一个 LangChain 程序

```python
"""
Day1 示例 1:第一个 LangChain 程序
直接调用 ChatOpenAI,传入消息列表
"""
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage

# 初始化 Chat Model
# model 参数指定模型名,temperature 控制随机性(0=确定性,1=随机)
model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

# 构造消息列表
messages = [
    SystemMessage(content="你是一个友好的中文助手,回答要简洁。"),
    HumanMessage(content="用一句话介绍 LangChain。"),
]

# 调用模型
response = model.invoke(messages)

# 输出结果
print("=== 模型回复 ===")
print(response.content)
print("\n=== 元数据 ===")
print(f"模型名称: {response.response_metadata.get('model_name', 'N/A')}")
print(f"Token 用量: {response.usage_metadata}")
```

运行后会看到模型的回复内容,以及 token 用量等元数据。

### 3.3 使用 ChatPromptTemplate

```python
"""
Day1 示例 2:使用 ChatPromptTemplate 参数化 Prompt
"""
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

# 初始化模型
model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

# 创建 Chat Prompt 模板
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个{role}。请用{style}的风格回答问题。"),
    ("human", "{question}"),
])

# 填充模板变量,生成消息列表
messages = prompt.invoke({
    "role": "历史老师",
    "style": "生动有趣",
    "question": "请用一句话介绍秦始皇。",
})

print("=== 生成的消息 ===")
for msg in messages.to_messages():
    print(f"[{msg.type}] {msg.content}")

# 交给模型处理
response = model.invoke(messages)
print("\n=== 模型回复 ===")
print(response.content)
```

### 3.4 流式输出

对于长文本生成,流式输出能显著提升用户体验:

```python
"""
Day1 示例 3:流式输出
"""
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个故事大王,擅长讲短小精悍的故事。"),
    ("human", "讲一个关于{topic}的小故事,100字以内。"),
])

chain = prompt | model

print("=== 流式输出 ===")
for chunk in chain.stream({"topic": "一只会编程的猫"}):
    print(chunk.content, end="", flush=True)

print("\n\n=== 流式输出结束 ===")
```

### 3.5 批量处理

当你需要同时处理多个输入时,用 `batch` 比循环调用 `invoke` 更高效:

```python
"""
Day1 示例 4:批量处理多个输入
"""
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

model = ChatOpenAI(model="gpt-4o-mini", temperature=0)

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个翻译助手,将中文翻译成{target_lang}。只输出译文。"),
    ("human", "{text}"),
])

# 用 LCEL 语法组成链(prompt | model 是 Day3 的内容,这里先体验)
chain = prompt | model

# 批量输入
inputs = [
    {"target_lang": "英文", "text": "今天天气真好"},
    {"target_lang": "日文", "text": "今天天气真好"},
    {"target_lang": "法文", "text": "今天天气真好"},
]

# 批量调用
responses = chain.batch(inputs)

print("=== 批量翻译结果 ===")
for i, resp in enumerate(responses):
    lang = inputs[i]["target_lang"]
    print(f"{lang}: {resp.content}")
```

### 3.6 完整示例:多轮对话(手动管理历史)

```python
"""
Day1 示例 5:多轮对话(手动维护历史消息)
注意:这只是演示,Day4 会学习用 Memory 自动管理历史
"""
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage, AIMessage

model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

# 手动维护消息历史
history = [
    SystemMessage(content="你是一个耐心的中文助手。"),
]

print("开始对话(输入 'quit' 退出):\n")

while True:
    user_input = input("你: ").strip()
    if user_input.lower() == "quit":
        print("再见!")
        break
    if not user_input:
        continue

    # 把用户输入加入历史
    history.append(HumanMessage(content=user_input))

    # 调用模型
    response = model.invoke(history)
    print(f"AI: {response.content}\n")

    # 把 AI 回复加入历史
    history.append(AIMessage(content=response.content))
```

## 六、练习题答案

### 1. 答案:B
**解析**:v0.3 起,各厂商集成独立成包,OpenAI 集成在 `langchain-openai` 中。`langchain` 是主包但不含具体厂商实现,`openai` 是 OpenAI 官方 SDK(非 LangChain 集成),`langchain-core` 只有核心抽象。

### 2. 答案:C
**解析**:`SystemMessage` 用于设定 AI 的行为/人设/规则,它在对话中通常放在最前面,对整个对话起指导作用。`HumanMessage` 是用户输入,`AIMessage` 是 AI 回复,`ToolMessage` 是工具调用结果。

### 3. 答案:B
**解析**:`{question}` 是 LangChain 模板变量的占位符,通过 `invoke({"question": "..."})` 填充。它不是 Python 的 f-string(不需要在字符串前加 f),而是在 `invoke` 时才进行替换。

### 4. 答案:C
**解析**:`stream()` 方法返回一个迭代器,逐块输出结果;`invoke()` 是单次调用返回完整结果;`batch()` 是批量处理多个输入。

### 5. 答案:LCEL(LangChain Expression Language)
**解析**:LCEL 是 LangChain Expression Language 的缩写,使用 `|` 管道符将组件串联,如 `prompt | model | parser`。这是 v0.3+ 推荐的写法,取代了旧的 `LLMChain` 等类。

### 6. 答案:0
**解析**:`temperature` 范围通常为 0-2,值为 0 时输出最确定(几乎每次相同),值越高随机性越大。代码生成、数据提取等任务建议设为 0,创意写作建议设为 0.7-1.0。

### 7. 参考答案:

```python
"""
练习题 7:代码解释器
"""
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

model = ChatOpenAI(model="gpt-4o-mini", temperature=0)

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个资深的编程老师,擅长用通俗易懂的中文解释代码。"),
    ("human", "请解释以下 {language} 代码的功能:\n\n```\n{code}\n```"),
])

code = """
def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)
"""

messages = prompt.invoke({
    "language": "Python",
    "code": code,
})

response = model.invoke(messages)
print(response.content)
```

### 8. 参考答案:

```python
"""
练习题 8:流式输出代码解释器
"""
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

model = ChatOpenAI(model="gpt-4o-mini", temperature=0)

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个资深的编程老师,擅长用通俗易懂的中文解释代码。"),
    ("human", "请解释以下 {language} 代码的功能:\n\n```\n{code}\n```"),
])

# 用 LCEL 组成链
chain = prompt | model

code = """
def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)
"""

print("=== 流式解释 ===")
for chunk in chain.stream({"language": "Python", "code": code}):
    print(chunk.content, end="", flush=True)

```
